# Plán dalších fází

1. Přidat více zakázek k objektu, historii zakázek a evidenci stavů nabídek.
2. Přidat až tři montážní návštěvy na zakázku a evidenci stavu fakturace.
3. Navrhnout auditní stopu pro opravy a zneplatnění uložené komunikace.
4. Posoudit požadavky na import, výstupy a případnou spolupráci více uživatelů.

Fáze 1 nemá automatickou synchronizaci, import ani plánování montáží. Firma může být archivována bez ztráty existujících přiřazení. Desktopový soubor databáze je přenositelný pomocí zálohy.
